# Release 1.0.0

- Local upload page with desktop, mobile, and combined video output.
- Complete-panel framing, configurable holds, protected push-in bounds, and full camera backtracking.
- Isolated focused panels with aspect-ratio-preserving rendering.
- Output-sized animation starting frames, original panel crops, ZIP downloads, and editing markers.
- Updated Windows launch scripts and installation documentation.

For borderless focused views, use 16:9 desktop panels or 9:16 mobile panels. A desktop 3x2 sheet is 8:3 excluding gutters; a mobile 2x3 sheet is 3:8 excluding gutters. Other panel ratios use neutral padding to preserve all content.
